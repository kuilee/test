What is the difference between intermediate and terminal operations in a Java Stream pipeline?

Intermediate Operations (Max 2)

Intermediate operations return another Stream and can be chained.


They are lazy and do not process elements until a terminal operation is invoked.


Examples include filter, map, distinct, sorted, limit, and skip.


They describe transformations or selections to apply to stream elements.

Terminal Operations (Max 2)

Terminal operations produce a result or side effect and end the pipeline.


Invoking a terminal operation triggers execution of the pipeline.


After a terminal operation, the stream cannot be reused.


Examples include collect, reduce, forEach, count, anyMatch, and findFirs

What is object polymorphism in Java, and how does it help you write flexible code?

What Is Polymorphism (Max 2)

Polymorphism allows the same interface or superclass type to refer to different concrete implementations.


The method that runs is chosen at runtime based on the actual object type (dynamic dispatch).


Subtypes can override behavior while callers program to a common abstraction.


It is closely related to inheritance and interface implementation.

Why Useful (Max 2)

Lets you extend behavior by adding new implementations without changing callers.


Reduces coupling to concrete classes.


Enables interchangeable strategies behind a shared API.


Makes code easier to test with alternate implementations or fakes.

Question
What are some key differences between ArrayList and LinkedList in Java, and when would you choose one over the other?

Key Differences (Max 4)

ArrayList is backed by a resizable array.


ArrayList provides fast indexed access.


ArrayList is usually better for iteration and general-purpose list usage.


LinkedList is backed by a doubly linked list.


LinkedList has slower indexed access because it must traverse nodes.


LinkedList can be useful for frequent insertions or removals when the node position is already known.


LinkedList generally has more memory overhead because each node stores links to neighboring nodes.

When to Use

Use ArrayList for most general-purpose list use cases, especially when reading, iterating, or accessing by index.


Use LinkedList when frequent insertions/removals at the beginning, end, or known iterator position are more important than indexed access.

Question
What is the difference between throw and throws in Java?

throw (Max 2)

throw is used to raise an exception at runtime.


It appears inside a method body with an exception instance, such as throw new IllegalArgumentException(…).


After throw executes, normal control flow stops and the exception propagates unless caught.


throw is about producing and signaling a failure.

throws (Max 2)

throws is used in a method declaration to declare checked exceptions the method may propagate.


It informs callers that they must handle or further declare those checked exceptions.


throws does not itself raise an exception; it documents and enforces the method’s exception contract.


Unchecked exceptions do not need to be declared with throws.

Question
What are the key differences between Comparable and Comparator in Java, and when would you use each?

Key Differences (Max 4)

Comparable defines the natural ordering of a class, while Comparator defines an external ordering.


Comparable requires modifying the class by implementing the Comparable interface, while Comparator can be implemented separately without changing the class.


Comparable defines a single default ordering, while multiple Comparator implementations can provide different sorting strategies.


Comparable implements the compareTo() method, while Comparator implements the compare() method.


Comparable is typically implemented by the class being sorted, while Comparator is supplied to sorting methods or collections when needed.

When to Use

Use Comparable when a class has a single, natural ordering that should always be available.


Use Comparator when different sort orders are required or when the class cannot or should not implement Comparable.
